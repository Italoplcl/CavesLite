# Repository layout

The current branch contains CavesLite 2.0 only. Production sources live in src/main/, current documentation in docs/, assets in assets/ and verification tools in tools/verification/.

Previous root duplicates, historical notes and old compiled JARs are excluded from the current files. Earlier versions remain recoverable from Git commit history, including baseline commit 2093a96d989e1b1d6fb514910f577c4ab6ebabf7. No Git history was rewritten.
